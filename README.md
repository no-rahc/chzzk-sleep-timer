# 수면 타이머

CHZZK나 YouTube 같은 영상을 틀어 놓고 잘 때 쓰려고 만든 Android용 수면 타이머입니다.
지정한 시간이 되면 **미디어 일시정지, 음량 0, 화면 잠금**을 원하는 조합으로 실행할 수 있습니다.

Android 9(API 28) 이상을 지원합니다.

## 주요 기능

- 매일 지정한 시각에 자동 실행
- 15 / 30 / 60 / 90분 빠른 타이머와 1~1440분 사용자 지정 타이머
- 매일 예약과 일회성 타이머 동시 사용
- 종료 30초 전부터 미디어 음량을 자연스럽게 줄이는 페이드 아웃
- 매일 예약 10분 전 알림과 `+5 / +20 / +40분` 오늘만 연장
- 상단 알림에서 종료 시각과 남은 시간 확인
- 알림에서 타이머 연장 및 Extra Dim 밝기 조절
- 재부팅, 시간/시간대 변경, 앱 업데이트 후 예약 자동 복구
- 정확한 알람을 사용할 수 없는 경우 근사 알람으로 자동 전환

## 설치

APK는 [GitHub Releases](https://github.com/no-rahc/chzzk-sleep-timer/releases)에서 받을 수 있습니다.

현재 배포 APK는 debug 서명 빌드입니다. 서로 다른 CI 실행에서 만든 APK는 서명이 달라 기존 앱 위에 업데이트가 되지 않을 수 있습니다.

## 필요한 권한

기능에 따라 아래 권한이 필요합니다.

| 기능 | 필요한 권한 |
|---|---|
| 미디어 일시정지 | 알림 접근 (`수면 타이머 미디어 제어`) |
| 화면 잠금 / Extra Dim | 접근성 (`수면 타이머 화면 잠금`) |
| 정확한 시각 실행 | 알람 및 리마인더 접근 |
| 타이머 상태 알림 | 알림 권한 (Android 13 이상) |

정확한 알람 권한은 필수는 아닙니다. 허용하지 않아도 예약은 유지되지만 Android의 배터리 정책이나 시스템 상태에 따라 실행 시각이 조금 늦어질 수 있습니다.

## 사용 방법

1. `실행 동작`에서 사용할 기능을 하나 이상 선택합니다.
2. 필요한 권한을 허용합니다.
3. 매일 반복하려면 실행 시각을 정하고 `지정한 시각에 매일 실행`을 켭니다.
4. 한 번만 사용할 때는 빠른 타이머를 누르거나 원하는 시간을 직접 입력합니다.
5. 처음 설정한 뒤에는 `지금 테스트`로 실제 동작을 한 번 확인하는 것을 권장합니다.

## 미디어 호환성

미디어 일시정지는 Android의 활성 미디어 세션을 이용합니다. CHZZK 전용 방식은 아니기 때문에 YouTube나 브라우저 재생에도 동작할 수 있지만, 앱이 미디어 세션을 노출하지 않는 경우에는 일시정지가 적용되지 않을 수 있습니다.

화면 잠금과 Extra Dim용 접근성 서비스는 화면 내용을 읽지 않으며 화면 잠금과 밝기 오버레이에 필요한 기능만 사용합니다.

## 빌드

JDK 17과 Android SDK 35가 필요합니다.

```bash
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

생성된 APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

프로젝트에 포함된 `build-debug.sh`를 사용하는 경우 `.tools/jdk`, `.tools/android-sdk` 경로가 준비되어 있어야 합니다.

변경 내역은 [CHANGELOG.md](CHANGELOG.md)에서 확인할 수 있습니다.
