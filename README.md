# 수면 타이머

Android 9(API 28) 이상에서 미디어 재생을 정리하고 화면을 잠그는 가벼운 수면 타이머 앱입니다.

## 주요 기능

- 매일 지정한 시각에 자동 실행
- 15/30/60/90분 빠른 일회성 타이머
- 1~1440분 사용자 지정 일회성 타이머
- 매일 예약과 일회성 타이머를 동시에 유지
- 실행 동작을 개별 선택
  - Android 활성 미디어 세션 일시정지
  - 미디어 음량을 0으로 변경
  - 접근성 서비스로 화면 잠금
- 실제 다음 예약 시각과 정확/근사 알람 상태 표시
- 재부팅·시간 변경·시간대 변경·앱 업데이트 후 예약 복구
- 최근 실행 시각, 실행 경로, 결과 표시
- Android 15 edge-to-edge 시스템 바 대응

## 사용 방법

1. 앱을 설치합니다.
2. `실행 동작`에서 필요한 동작을 선택합니다. 최소 1개는 켜져 있어야 합니다.
3. 필요한 경우 아래 권한을 허용합니다.
   - `미디어 일시정지` 사용 시: 알림 접근의 `수면 타이머 미디어 제어`
   - `화면 잠금` 사용 시: 접근성의 `수면 타이머 화면 잠금`
   - 정확한 시각 실행이 필요할 때: `알람 및 리마인더` 접근
4. 매일 반복하려면 실행 시각을 선택하고 `지정한 시각에 매일 실행`을 켭니다.
5. 한 번만 사용하려면 `빠른 타이머`에서 시간을 선택하거나 직접 입력합니다.
6. 처음 설정한 뒤에는 `지금 테스트`로 실제 기기에서 동작을 확인하는 것을 권장합니다.

Android 12 이상에서 정확한 알람 접근을 허용하지 않아도 타이머 예약 자체는 유지됩니다. 다만 Android가 배터리 상태와 시스템 정책에 따라 실제 전달 시각을 늦출 수 있으며 앱은 이를 `근사 알람`으로 표시합니다.

## 예약 복구

매일 예약과 일회성 타이머는 별도의 `PendingIntent`로 관리되어 서로 덮어쓰지 않습니다. 다음 상황에서 저장된 예약을 다시 구성합니다.

- 기기 재부팅
- 시스템 시각 변경
- 시간대 변경
- 앱 업데이트
- 정확한 알람 권한 상태 변경
- 앱 재실행/복귀

오래 지나 이미 의미가 없어진 일회성 타이머는 부팅 후 갑자기 화면을 잠그지 않도록 일정 유예 시간 뒤 자동 폐기합니다.

## 미디어 호환성

미디어 일시정지는 Android가 활성 미디어 세션으로 노출한 재생에 대해 동작합니다. YouTube, CHZZK, 브라우저 등의 재생이 기기/앱 버전에 따라 미디어 세션을 노출하지 않으면 해당 세션은 건너뛸 수 있습니다. 다른 실행 동작은 별도로 계속 시도합니다.

화면 잠금용 접근성 서비스는 화면 내용을 가져오지 않으며 `GLOBAL_ACTION_LOCK_SCREEN`만 사용합니다.

## 빌드 및 검증

JDK 17과 Android SDK 35가 필요합니다.

```bash
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

APK 위치:

```text
app/build/outputs/apk/debug/app-debug.apk
```

기존 `build-debug.sh`는 프로젝트의 `.tools/jdk`, `.tools/android-sdk` 경로가 준비된 환경에서 사용할 수 있습니다.

```bash
./build-debug.sh testDebugUnitTest lintDebug assembleDebug
```

GitHub Actions의 `Android CI`도 단위 테스트, lint, debug APK 빌드를 수행하고 APK artifact를 업로드합니다.

## APK 서명

현재 저장소에는 배포용 keystore를 커밋하지 않습니다. CI에서 생성하는 APK는 설치 가능한 debug 서명 빌드이므로 다른 CI 실행에서 만들어진 APK와 서명이 달라질 수 있습니다. 고정된 배포 서명키를 GitHub Actions secret 등 안전한 위치에 구성하기 전까지는 기존 CI APK 위에 업데이트 설치가 보장되지 않습니다.
